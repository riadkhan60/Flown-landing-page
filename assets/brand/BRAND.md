# Flown brand assets

Made from Qbexel's Flown brand kit, as copied into the app repository
([samiulakhan12/windows-screen-studio](https://github.com/samiulakhan12/windows-screen-studio),
`assets/brand`). Take new artwork from there rather than editing these files.

| File | Made from | Used for |
| --- | --- | --- |
| `flown-logo.svg` | `flown-mark-flat.svg` and `flown-wordmark-white.svg`, the wordmark in Ink for light backgrounds, laid out as the kit's horizontal logo (wordmark 0.52 of the mark's height, 0.16 of it away) | the logo in the page header |
| `../flown-icon.svg` | `flown-app-icon-small.svg`, unchanged | the favicon |

## Colour

| Name   | Hex       | Use |
| ------ | --------- | --- |
| Cyan   | `#3FCBFF` | gradient start |
| Azure  | `#4D9BFF` | gradient |
| Indigo | `#6252FC` | gradient; the accent (buttons, links, focus) |
| Violet | `#8B3AFF` | gradient end |
| Ink    | `#0D0F1C` | text, dark wordmark |

The hero's wallpaper and the export frames use the four gradient colours.

## Usage rules (from the kit)

- Keep clear space of about 40% of the mark's height around the logo.
- Show the horizontal logo at least 96 px wide.
- Use the gradient mark on Ink or white; on photos or busy colour, the solid white or black logo.
- Don't recolour the blades, rotate or skew the mark, add effects, or set the wordmark in another
  typeface.
